# End-Point Football Scanner (v4)

Headless end-point scanner (`1X`, `12`, `Over 1.5`) with zero-leakage EWMA + Poisson + league-tempo modeling, regularized per-market L-BFGS-B optimization (`market_optimizer.py`), focused leagues (`I1,E3,EC,E2,E0,I2,B1,N1`), `>= 1.25` minimum leg odd, and `2%` (`400` on `20,000`) bankroll tracking.
